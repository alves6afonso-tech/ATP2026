**Blockly Puzzle: Barco à vela**

Este exercício senti que foi mais fácil que o outro, apenas demandava mais tempo e paciência para fazer todo o desenho. Foi um processo simples, porém demorado devido à falta de conhecimento provavelmente era capaz de reduzir este código extenso por um mais conciso. No geral não tive dificuldades e sinto que me ajudou a perceber melhor os comandos básicos do jogo.

Não fiz o desenho exatamente igual porque sinto que o objetivo era mais sobre aprender acerca das funcionalidades e começar a introduzir o código e a criatividade para fazer determinadas formas. Como fiz todo o tipo de formas exigidas não senti necessidade de as repetir.
